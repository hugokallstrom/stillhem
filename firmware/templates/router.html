Set up your router

Stillhem only blocks once your router sends every device's DNS to it. Set your router's DNS server to this device's address:

{{ pi_ip }}

Generic steps

  1. Open your router's admin page in a browser (often 192.168.0.1 or 192.168.1.1).
  2. Log in (the password is usually on a sticker on the router).
  3. Find the DNS setting — usually under Internet, LAN, or DHCP.
  4. Set the primary DNS server to {{ pi_ip }}. Clear any secondary DNS, or set it to the same address.
  5. Save, then reconnect a device (or wait a few minutes) for it to take effect.

Instructions for common routers

Telia

Telia Router → Avancerade inställningar → Nätverk / LAN → DNS. Set primary DNS to {{ pi_ip }}.

Tele2 / Comhem

Login at the router's address → Inställningar → Nätverk → DHCP/DNS. Set DNS to {{ pi_ip }}.

Bahnhof

Router admin → LAN / DHCP-server → DNS. Set to {{ pi_ip }}.

Telenor

Telenor router → Inställningar → Nätverk / LAN → DNS. Set to {{ pi_ip }}.

Asus

asusrouter.com → LAN → DHCP Server → "DNS Server 1" = {{ pi_ip }}.

TP-Link

tplinkwifi.net → Advanced → Network → DHCP Server → Primary DNS = {{ pi_ip }}.

Netgear

routerlogin.net → Advanced → Setup → Internet/LAN Setup → DNS = {{ pi_ip }}.

If your router won't let you change DNS

Some ISP-locked routers don't allow it. You can instead set the DNS to {{ pi_ip }} on each device (phone/computer Wi-Fi settings → DNS), though that only covers the devices you change.
